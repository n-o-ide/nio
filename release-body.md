# NioAI 0.2.1

NioAI 0.2.1 includes refreshed project documentation and screenshots of the inline CLI and full-screen TUI.

## Highlights

- **README screenshots:** see the inline CLI and full-screen TUI in the project documentation.
- **Project documentation:** updated install, usage, queue, skills, session, file input, and TUI guidance.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/nio-labs/nio/main/install.sh | bash
```

Or install the npm launcher:

```sh
npm install -g @nio-labs/nio-ai
```
